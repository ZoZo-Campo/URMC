# Socle commun

Ce package fournit l’adaptateur ROS, la perception, les protections de commande et le simulateur 2D partagé. Les logiques propres aux épreuves sont dans les packages de mission.

Le simulateur et son interface travaillent sous `/urmc_sim/mXX`. Le mode robot utilise les topics matériels et démarre désarmé. Voir la documentation à la racine du dépôt.
